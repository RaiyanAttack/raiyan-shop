# Raiyan non-Firebase website

1. Install Node.js 20+.
2. Copy `.env.example` to `.env` and change `JWT_SECRET`.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000/`
6. Admin: `http://localhost:3000/admin.html`

Admin login: Raiyan / raiyan123

This package is Firebase-free. The included frontends use the Node/SQLite API. It is a clean replacement/starter and does not preserve every feature of the old Firebase frontend.
